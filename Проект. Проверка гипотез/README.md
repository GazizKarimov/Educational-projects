# ЯндексКниги: проверка гипотезы об активности пользователей

Проверка гипотезы о том, что пользователи из Санкт-Петербурга в среднем проводят больше времени за чтением и прослушиванием книг в приложении, чем пользователи из Москвы.

## О проекте

Учебный проект, выполненный в рамках практики по проверке статистических гипотез. Его основная цель — отработать предобработку данных и статистическое сравнение двух независимых выборок. Часть аналитических выводов в тетрадке требует более строгой проверки, поэтому к конкретным числовым заключениям стоит относиться с осторожностью.

## Цель

С помощью статистического теста проверить гипотезу: пользователи из Санкт-Петербурга проводят в среднем больше времени за чтением и прослушиванием книг в приложении, чем пользователи из Москвы.

## Данные

Датасет с активностью пользователей в Москве и Санкт-Петербурге, предварительно выгруженный из базы данных с помощью SQL: город, идентификатор пользователя, суммарная длительность чтения и прослушивания в часах. Файл в репозиторий не включён.

## Что сделано

- предобработка данных: проверка полных дубликатов и дубликатов по идентификатору пользователя (пересечение выборок городов);
- сравнение размеров и описательной статистики выборок, обработка выбросов по 99-му процентилю;
- сравнение распределений активности между городами;
- проверка гипотезы тестом Уэлча (в связи с разными дисперсиями выборок);
- составление аналитической записки по результатам.

## Результаты

Различие в средней активности между городами статистически значимо: пользователи из Санкт-Петербурга в среднем проводят больше времени в приложении, чем пользователи из Москвы. В работе отдельно отмечено, что причина различия не установлена и требует дополнительного анализа (возможное влияние возраста аудитории, особенностей региона или пользовательских привычек).

## Инструменты

Python, pandas, matplotlib, scipy.
