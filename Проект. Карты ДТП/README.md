# Исследование данных о ДТП

Предобработка и анализ данных о дорожно-транспортных происшествиях в Московской и Кировской областях для некоммерческого проекта «Карта ДТП»: оценка качества данных и ответы на вопросы о динамике аварийности.

## Контекст

«Карта ДТП» — некоммерческий проект, посвящённый проблеме дорожно-транспортных происшествий в России, цель которого — повысить безопасность на дорогах. Заказчик хочет собирать данные более высокого качества и ожидает рекомендаций, на какие проблемы или особенности стоит обратить внимание.

## Цель

Провести предобработку сырых данных и ответить на вопросы:
- как менялось число ДТП по временным промежуткам;
- различается ли число ДТП для групп водителей с разным стажем.

## Данные

Данные о ДТП по двум регионам (Кировская и Московская области), по три датасета на регион, связанные между собой идентификатором ДТП `id`:
- сведения о происшествии (координаты, освещённость, погода, дата и время, число пострадавших и участников и др.);
- сведения об участниках (роль, пол, нарушения ПДД, состояние здоровья, стаж вождения);
- сведения о транспортных средствах (год выпуска, марка, модель, цвет, категория).

Файлы в репозиторий не включены.

## Что сделано

- предобработка данных: приведение типов, проверка пропусков и значений-заглушек по всем шести таблицам;
- проверка дубликатов с учётом структуры данных «один ко многим» (в одной аварии может быть несколько участников и транспортных средств);
- анализ изменения числа ДТП по дням недели и месяцам для обоих регионов;
- анализ связи числа ДТП со стажем водителей с выделением категорий по 5 лет;
- оценка применимости выводов с учётом ограничений доступных данных.

## Результаты

- значимых дубликатов, искажающих данные, не выявлено: формально повторяющиеся `id` в таблицах участников и транспортных средств — ожидаемое следствие того, что в одной аварии участвует несколько человек или машин, а не дефект данных; полные дубликаты (до 38% в участниках, около 1% в ТС) стоит обсудить с заказчиком, возможная причина — параллельное оформление отчёта разными сотрудниками ДПС;
- пропуски в поле со стажем (до 46%) по крайней мере частично объясняются тем, что часть участников ДТП не являются водителями;
- чаще всего аварии происходят в пятницу и субботу, пик по месяцам — август;
- по доступным данным нельзя корректно сравнить категории водителей по стажу: число ДТП в категории отражает в первую очередь число водителей в ней, а не риск аварии — для содержательного вывода не хватает данных об общем числе водителей по категориям стажа в каждом регионе.
