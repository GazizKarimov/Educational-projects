# Интернет-магазин: анализ результатов A/B-теста

Оценка эффективности изменения интерфейса сайта интернет-магазина по результатам A/B-теста: проверка корректности проведения теста и статистическая оценка изменения конверсии.

## О проекте

Учебный проект, выполненный в рамках практики по A/B-тестированию. Его основная цель — отработать проверку корректности эксперимента (равномерность групп, отсутствие пересечений, достаточность выборки) и статистическую проверку гипотезы о приросте конверсии. Часть аналитических выводов в тетрадке требует более строгой проверки, поэтому к конкретным числовым заключениям стоит относиться с осторожностью.

## Цель и гипотеза

**Цель:** оценить эффективность изменения интерфейса сайта интернет-магазина.

**Гипотеза:** упрощение интерфейса приведёт к тому, что в течение семи дней после регистрации конверсия зарегистрированных пользователей в покупателей увеличится как минимум на три процентных пункта.

## Данные

Таблица участников теста (`user_id`, группа, тест, устройство) и таблица событий 2020 года (`user_id`, дата и время события, тип события). Файлы в репозиторий не включены.

## Что сделано

- проверка целостности и корректности типов данных;
- проверка равномерности распределения пользователей по устройствам и отсутствия пересечений между группами;
- фильтрация событий по горизонту анализа (7 дней с момента регистрации);
- расчёт необходимого размера выборки для заданных параметров теста;
- оценка изменения ключевой метрики (конверсии в покупку) и проверка его статистической значимости.

## Ключевые результаты по данным теста

- фактический размер каждой группы (~5,5 тыс. пользователей) превысил расчётный минимум (3 761 на группу);
- конверсия в тестовой группе выросла на 1,78 процентного пункта относительно контрольной;
- результат статистически значим, однако прирост оказался меньше заявленных в гипотезе трёх процентных пунктов.
