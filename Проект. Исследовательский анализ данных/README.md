# Инвестиции в стартапы: исследовательский анализ данных

Анализ исторических данных о венчурных и других инвестициях в стартапы с целью определить, в какие отрасли и на каких условиях выгоднее было инвестировать.

## О проекте

Учебный проект, выполненный в рамках практики по анализу данных. Его основная цель — отработать инструменты `pandas` и визуализации (`matplotlib`, `seaborn`): очистку данных, обработку выбросов, объединение нескольких таблиц, построение сводных таблиц и графиков. Часть аналитических выводов в тетрадке требует более строгой проверки (в частности, расчёт доходности по типам финансирования), поэтому к конкретным числовым заключениям и рекомендациям стоит относиться с осторожностью.

## Цель

Определить наиболее подходящую область и стратегию инвестирования.

## Данные

Два датасета:
- сведения о компаниях и привлечённом финансировании (название, рынок, регион, объём и тип финансирования, статус компании, даты);
- сведения об объёмах возвратов по годам и типам финансирования.

Файлы в репозиторий не включены.

## Что сделано

- предобработка данных: пропуски, дубликаты, типы данных, обработка выбросов;
- анализ по типам и срокам финансирования, регионам и отраслям;
- анализ динамики числа сделок и объёма возвратов по годам;
- сопоставление вложений и возвратов по разным типам финансирования.

## Инструменты

Python, pandas, matplotlib, seaborn.
