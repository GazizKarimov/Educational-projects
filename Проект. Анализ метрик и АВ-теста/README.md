# A/B-тест: новый алгоритм рекомендаций в развлекательном приложении

Разработка и анализ A/B-теста для приложения с «бесконечной» лентой контента: расчёт параметров теста, проверка корректности его проведения и анализ результатов эксперимента по внедрению нового алгоритма подбора рекомендаций.

## О проекте

Учебный проект, выполненный в рамках практики по продуктовой аналитике и A/B-тестированию. Его основная цель — отработать полный цикл теста: расчёт размера выборки и длительности эксперимента, проверку корректности сплитования, статистическую проверку гипотезы. Часть аналитических выводов в тетрадке требует более строгой проверки, поэтому к конкретным числовым заключениям стоит относиться с осторожностью.

## Цель

Рассчитать параметры теста, оценить корректность его проведения и проанализировать результаты эксперимента.

## Данные

Исторические и тестовые данные о пользовательских сессиях (дата и время сессии, дата установки и регистрации, число просмотренных страниц, устройство, регион). Файлы в репозиторий не включены.

## Что сделано

- исследовательский анализ исторических данных: динамика регистраций, глубина просмотра, доля «успешных» сессий;
- расчёт необходимого размера выборки и длительности теста;
- мониторинг теста: проверка равенства групп, отсутствия пересечений и равномерности распределения по устройствам и регионам;
- статистическая проверка изменения ключевой метрики (доли успешных первых сессий) между группами.

## Ключевые результаты по данным теста

- расчётный размер выборки — 41 040 пользователей на группу, расчётная длительность теста — 9 дней;
- фактически в тест попало около 15 тыс. пользователей на группу — заметно меньше расчётного объёма;
- изменение ключевой метрики оказалось статистически не значимым (p-value 0.58 при уровне значимости 0.05), что, вероятно, связано с недостаточным объёмом выборки.

Python, pandas, matplotlib, scipy, statsmodels.
