# Проверка соответствия разделов 4.2 и 4.3 отчёта по ПЭК

Поиск расхождений между разделами отчёта производственного экологического контроля (ПЭК): раздел 4.2 (сведения об образовании, получении и передаче отходов) и раздел 4.3 (сведения о получении и передаче отходов). Расхождение сопоставляется с Риском 7 по требованиям Приказа Минприроды РФ.

## Контекст

Ежегодно до 25 марта природопользователи, эксплуатирующие объекты, оказывающие негативное воздействие на окружающую среду (НВОС) I, II и III категорий, обязаны сдавать отчёт о проведении ПЭК согласно ФЗ № 7 «Об охране окружающей среды» и Приказу Минприроды России от 18.02.2022 № 109. По разным причинам данные в отчёте могут содержать ошибки, в том числе расхождения между разделами по количеству принятых и переданных отходов.

## Цель

Определить количество отчётов ПЭК с несоответствием между разделами 4.2 и 4.3 по критерию Риска 7 (сопоставление по ИНН и идентификатору отхода).

## Данные

Два файла отчётности ПЭК (раздел 4.2 и раздел 4.3) и словарь-описание полей. Данные содержат ИНН организаций и сведения о движении отходов, поэтому в репозиторий не включены.

## Что сделано

- сверка структуры предоставленных данных с формами разделов 4.2 и 4.3 по Приказу Минприроды РФ от 15.03.2024 № 173;
- определение допущений для расчёта (один уникальный отчёт = один ИНН, ввиду отсутствия идентификатора объекта НВОС в данных);
- расчёт общего количества уникальных отчётов ПЭК;
- поиск организаций, заполнивших только один из разделов;
- сопоставление объёмов приёма/передачи отходов на уровне «ИНН + вид отхода» между разделами;
- классификация выявленных нарушений по видам (Риск 7.1, 7.2, 7.3) с расчётом их доли.

## Результаты

- всего проанализировано 58 202 отчёта ПЭК;
- отчётов с нарушением по Риску 7: 14 324 (24,61% от общего числа);
- основной вклад в нарушения (76,3% случаев) — несовпадение объёма отходов на уровне «ИНН + вид отхода» при заполненных обоих разделах.
